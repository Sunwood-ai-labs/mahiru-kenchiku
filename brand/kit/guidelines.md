# マヒル建築 ― ロゴ使用ガイドライン（簡易版）

## 1. ロゴについて
- **意味**: 2本の材を段継ぎで組み合わせた継ぎ目。「この会社で段があるのは、継ぎ手だけ」――床の段差をなくす家づくり（設計原則1）と、日本の木工の職人仕事を一つの形にしたもの。
- **基本形**: 横組み・和文（`lockups/mahiru-horizontal-jp.svg`）が国内向けの主署名。横組み・欧文、縦組み、シンボル単体、ワードマーク単体も用意してある。
- **ファイル**: 画面用は `symbol/` `lockups/` の SVG／PNG、Web アイコンは `web-icons/`。印刷所へは SVG を渡し、CMYK 値は下表の近似値を使うこと。

## 2. クリアスペース（周囲の余白）
ロゴの四辺に、**x = 継ぎ目の1段の高さ**（シンボルでは段と段の落差分）以上の余白を空ける。余白はロゴの大きさに比例させる。決まった mm 数で固定しない。

## 3. 最小サイズ
| バージョン | 画面 | 印刷 |
|---|---|---|
| 横組みロックアップ | 幅 120px 以上 | 幅 30mm 以上 |
| シンボル（通常版） | 32px 以上 | 8mm 以上 |
| シンボル（小サイズ版 `-small`／favicon） | 16px から可 | ― |

32px 未満では必ず小サイズ版（継ぎ目を太くした専用原稿）を使うこと。通常版をそのまま縮小しない。

## 4. 色
| 名前 | HEX | RGB | CMYK（近似） |
|---|---|---|---|
| 真昼の藍 Mahiru Indigo | #1E3A5F | 30 / 58 / 95 | 68 / 39 / 0 / 63 |
| 墨 Sumi Black | #000000 | 0 / 0 / 0 | ― |
| 白 White | #FFFFFF | 255 / 255 / 255 | ― |

- 使える組み合わせ: 藍の単色版を白地に／白版を藍地に／白版を黒地に／黒版を白地に。
- 藍は白地に対してコントラスト比 約11.5:1。本文の文字色にも使える。
- Pantone 指定は未選定。看板など色の再現が重要な場合は、印刷所・看板業者と現物合わせをすること。

## 5. 書体
- ワードマークは Noto Sans Bold／Noto Sans CJK Bold（SIL OFL 1.1）をアウトライン化した原稿。**文字を打ち直して再現しないこと**（必ず原稿ファイルを使う）。
- 文書・Web の本文書体は Noto Sans CJK を推奨。無い環境では OS 標準のゴシックで代替可。

## 6. 禁止事項
- 縦横比を変える／回転させる／グラデーション・影・輪郭線などの効果を付ける
- パレット以外の色に変える
- ロックアップ内のシンボルと文字の位置関係・大きさの比率を変える
- 継ぎ目の段の数を変える、継ぎ目を直線に変えるなど、シンボルの形状を変える
- 写真や柄の上にそのまま置く（白版または黒版を、落ち着いた部分に置くこと）

## 7. 管理
- マスターファイルの保管場所: `~/workspace/logo-brand/kit/`（このフォルダ一式）
- 迷ったら: シンボル単体＋藍、が最も安全な使い方。
