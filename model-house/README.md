# model-house/ — MAHIRU Model 01「真昼の平屋」

マヒル建築のモデルハウス第1棟の試作モデルです。Pascal Editorで構築し、FreeCAD 1.1.4で取り込み検証を行いました。

## 仕様（実測）

- 平屋 11.0×8.5m、5室：リビング 30㎡／キッチン 25㎡／主寝室 17.5㎡／バスルーム 8.75㎡／可変室（旧・寝室2）12.25㎡
- 壁16・ドア5・窓9、家具19点
- 切妻屋根 35°、軒の出 0.4m、壁厚 100mm、壁高さ 2,450mm、棟高 約5.7m

## ファイル

- `scene.json` — Pascal EditorのシーンJSON
- `mahiru-model01.glb` — GLB書き出し（460KB、元ファイル名 `ui-model_2026-11-01.glb`）
- `pascal_house_from_freecad.stl` — FreeCAD経由のSTL
- `pascal_house.FCStd` — FreeCADファイル（GLB取り込み：Partシェル266個＋グループ42。ネイティブソリッドではなく参照モデルとして扱う）
- `MAHIRU-model01-notes.md` — コンセプト反映メモ（シーン名変更の記録、可変室の再定義、次の反映候補）
- `screenshots/` — 3D表示と間取り（2Dプラン）

## 正直な未達事項

- 洗面台・洗濯機置場が未配置で、「洗う→干す→しまう」動線は未実証です（原則1の次の課題）。
- 断熱性能（UA値・室間温度差）はこのモデルでは検証できません。実設計では性能計算で担保します。
