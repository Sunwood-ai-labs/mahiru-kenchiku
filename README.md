# 株式会社マヒル建築 — MAHIRU KENCHIKU

> **階段のない朝と、真昼のように明るいワンフロアを、子育てを終えた夫婦の残り30年に届ける。**

神奈川県藤沢市を拠点に、平屋の注文住宅だけを建てる小さな建築会社です。新築のみ、年8棟まで。施工は車で60分圏（藤沢・鎌倉・茅ヶ崎・平塚・横浜南部）に限ります。

**誰に:** 子育てを終えた55〜65歳の夫婦。築30年超の2階建てから、70〜95㎡の平屋へ住み替える方へ。
**何を:** 平屋という建物ではなく、階段のない朝、温度差のない家、洗濯がワンフロアで終わる暮らしの変化を届けます。

> **ロゴはD案に決定しました（2026-11-01）。** 社長 maki が第2ラウンド推奨のD案「継ぎ手の段」を選択し、確定フルキット（ブランドカラーは真昼の藍 #1E3A5F）は `brand/kit/` に収録しています。決定までのコンセプト案8案（A 真昼の水平線／B Mの谷の太陽／C 太陽の中の家／D 継ぎ手の段／E 動く仕切り／F 真昼の短い影／G 温もりの稜線／H 朝の光の通り道）も経緯として `brand/` に残しています。

## 設計原則 — 3つだけ

1. **ワンフロア完結** — 寝る・起きる・洗う・洗濯する・干す・しまうを同一フロアに。室内の段差はゼロを標準とし、ドアは引き戸を標準にします。
2. **温度の段差ゼロ** — 断熱等級6相当（UA値0.46以下を設計目標）、冬の朝の室間温度差3℃以内を物差しに。風呂・脱衣・洗面・トイレ・主寝室を一塊に寄せます。吹き抜けは作りません。
3. **部屋に固定名を与えない** — 主寝室以外の部屋は「子ども部屋」「客間」と名付けません。孫の宿泊部屋から趣味部屋、将来の介護の部屋へ、名前が変わる部屋として設計します。

やらないこと: 2階建ては建てません。営業資料で「終の住まい」「バリアフリー」という言葉を使いません。お客様の言葉（「階段がつらい」「風呂が寒い」）で語ります。

## モデルハウス — MAHIRU Model 01「真昼の平屋」

平屋 11.0×8.5m、5室（リビング30㎡／キッチン25㎡／主寝室17.5㎡／バスルーム8.75㎡／可変室12.25㎡）、切妻屋根35°、家具19点。Pascal Editorで構築し、FreeCADで検証した試作モデルです。
