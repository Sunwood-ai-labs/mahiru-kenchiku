## 🌞 ミッション

> 階段のない朝と、真昼のように明るいワンフロアを、子育てを終えた夫婦の残り30年に届ける。

「誰に」＝子育てを終えた夫婦、「何を」＝階段のない朝＋真昼の明るさのあるワンフロア、「どれだけ」＝残り30年、までを一文に含めました。「豊かな暮らし」「安心と信頼」のような言葉は使いません。届けるものを場面（朝）と光（真昼）で言い切ります。

## 👥 誰に・何を

**誰に:** 子育てを終えた55〜65歳の夫婦。築30年超の2階建て（延床118㎡前後）から、70〜95㎡の平屋へ住み替える方へ。施工は藤沢・鎌倉・茅ヶ崎・平塚・横浜南部（車で60分圏）、年8棟まで、新築のみです。

**何を:** 平屋という建物ではなく、暮らしの場面の変化を届けます。

- **朝** — 目覚めてから朝食まで階段の昇降ゼロ。冬でも裸足で洗面所まで歩ける
- **風呂** — 脱衣所・浴室・寝室・トイレを一塊に寄せ、寒い廊下を渡らない
- **洗濯** — 洗う→干す→しまうがワンフロアで完結し、カゴを持って階段を上る作業が消える
- **週末** — 掃除はロボット掃除機＋30分。残りの時間は庭と自転車と孫に
- **10年後・20年後** — 第二の寝室は名前が変わる。孫の宿泊部屋→趣味部屋→将来の介護の部屋へ

## 📐 設計原則 — 3つだけ

1. **ワンフロア完結** — 寝る・起きる・洗う・洗濯する・干す・しまうを同一フロアに。室内の段差はゼロを標準とし、ドアは引き戸を標準にします。
2. **温度の段差ゼロ** — 断熱等級6相当（UA値0.46以下を設計目標）、冬の朝の室間温度差3℃以内を物差しに。風呂・脱衣・洗面・トイレ・主寝室を一塊に寄せます。吹き抜けは作りません。
3. **部屋に固定名を与えない** — 主寝室以外の部屋は「子ども部屋」「客間」と名付けません。入口は有効900mm以上、介助スペースの下地を最初から入れます。

やらないこと: 2階建ては建てません。「終の住まい」「バリアフリー」という言葉は使いません。お客様の言葉（「階段がつらい」「風呂が寒い」）で語ります。

## 🏡 モデルハウス — MAHIRU Model 01「真昼の平屋」

平屋 11.0×8.5m、5室（リビング30㎡／キッチン25㎡／主寝室17.5㎡／バスルーム8.75㎡／可変室12.25㎡）、切妻屋根35°、窓9箇所、家具19点。Pascal Editorで構築し、FreeCAD 1.1.4で取り込み検証した試作モデルです。

- データと検証メモ: [`model-house/`](model-house/) ／ [`docs/`](docs/)
- 正直な未達事項: 洗面台・洗濯機置場が未配置で「洗う→干す→しまう」動線は未実証です。断熱性能もこのモデルでは検証できません（実設計では性能計算で担保します）
